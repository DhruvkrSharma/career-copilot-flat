## 📋 What This Does

Career Copilot is a complete **career operating system** for AI/ML engineers. Instead of evaluating just your resume, it evaluates your entire candidate package:

- **Resume** — ATS compatibility, keyword density, multi-placement scoring, keyword preservation
- **GitHub** — Profile presentation, code quality, documentation
- **LinkedIn** — Recruiter visibility, professional brand, network
- **Projects** — Technical depth, deployment, evaluation pipelines, observability
- **Interview Readiness** — STAR answers, agentic AI design, system design, evaluation skills
- **Market Fit** — Alignment with 2026 hiring trends (agentic AI, LLMOps, multi-modal, MCP)

## ✨ Key Features (June 2026)

### 🛡️ ATS Score Protection System
The `career optimize` command guarantees your ATS score **never decreases** during optimization:

1. **Baseline scoring** — Records your current ATS score before any changes
2. **Keyword preservation** — Catalogs every existing keyword and locks them in
3. **Gap filling** — Adds missing keywords from the job description and role bank
4. **Multi-placement** — Ensures keywords appear in Skills AND contextual bullets
5. **Post-rewrite verification** — Re-scores and blocks output if ATS score dropped
6. **Score gate loop** — If score dropped, automatically revises until it's ≥ baseline

## 📝 Changelog

### June 2026 — Major Update

**ATS Score Protection (Bug Fix)**
- Fixed critical bug where resume optimization was *reducing* ATS scores instead of increasing them
- Root cause: Rewrite process was replacing keywords with synonyms (e.g., "TensorFlow" → "deep learning framework")
- Added 5-step keyword preservation pipeline: Extract → Preserve → Add → Verify → Gate
- Added post-rewrite ATS re-verification with PASS/FAIL verdict
- Added `career optimize` mandatory execution order (Baseline → Gap Analysis → Rewrite → Verify → Score Gate)

**ATS Scoring Overhaul (Original Fix)**
- ATS weight in resume rubric increased from 15 → 20 points
- ATS review originally added keyword density, multi-placement, and JD phrase matching scoring

**Structural Architecture Fixes (Latest Update)**
- **Evidence-Based ATS Model**: Replaced folk-theory keyword density targets with a parseability-focused, recruiter-search model. Focus is now on real parsing risks (formatting, fonts, unselectable text) and keyword presence rather than density.
- **Rubric Calibration**: Added clear, reproducible calibration anchors across all 5 rubrics so scores are consistent and not falsely precise. Included an honesty check to score metrics as-stated but flag implausible claims.
- **Data Acquisition Preconditions**: Wired in explicit data-acquisition instructions for GitHub and LinkedIn in the orchestration prompt. The model will now ask for the profile content rather than stalling or hallucinating.
- **Centralized Rules**: Consolidated keyword preservation and rewrite rules into `resume_best_practices.md` as the canonical source to prevent drift across multiple prompt files.
- **Data Decay Controls**: Added explicit "verify live before quoting" staleness warnings to volatile data files (`market_intelligence.md`, `ai_ml_keywords.md`) regarding salaries, model names, and market trends.
- **Contradiction Fix**: Resolved contradictory guidance around System Design rounds (now scaled by level rather than gated).

**Knowledge Base — Updated to June 2026**
- `ai_ml_keywords.md` — Latest models (GPT-5.5, Claude Opus 4.8, Gemini 3.x, Llama 4), new frameworks (LangGraph, OpenAI Agents SDK, Google ADK), new paradigms (MCP, A2A, Agentic RAG), 2 new roles
- `market_intelligence.md` — 2026 salary data, agentic AI as #1 skill, new roles, updated company lists, interview trend shifts
- `interview_knowledge.md` — Agentic AI interview section, LLMOps, AI Safety, reasoning models, 2026-specific behavioral themes
- `project_patterns.md` — 5 S-tier project archetypes, observability requirements, overused projects to avoid, updated tier classifications
- `resume_best_practices.md` — Separate section priority for GenAI vs ML roles, 2026 strong examples (agentic systems, model routing, fine-tuning), cost metrics, evaluation maturity, observability
