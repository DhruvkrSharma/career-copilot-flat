# GitHub Profile Scoring Rubric

**Total Score: 100 points**

---

## 1. Profile Completeness (10 points)

| Criteria | Points |
|----------|--------|
| Profile picture | 2 |
| Bio with relevant description | 3 |
| Pinned repositories (4–6) | 3 |
| Links (website, LinkedIn) | 2 |

## 2. Repository Quality (25 points)

| Criteria | Points |
|----------|--------|
| README quality | 5 |
| Code organization | 5 |
| Documentation | 5 |
| .gitignore & config | 3 |
| License | 2 |
| Requirements/Dependencies | 5 |

## 3. Technical Depth (20 points)

| Criteria | Points |
|----------|--------|
| Project complexity | 7 |
| Variety of technologies | 5 |
| AI/ML specific projects | 5 |
| Testing | 3 |

## 4. Activity & Consistency (15 points)

| Criteria | Points |
|----------|--------|
| Contribution frequency | 5 |
| Recent activity (last 3 months) | 5 |
| Commit quality (meaningful messages) | 5 |

## 5. Software Engineering Practices (15 points)

| Criteria | Points |
|----------|--------|
| Branching strategy | 3 |
| Issue tracking | 3 |
| Code reviews (PR evidence) | 3 |
| CI/CD (GitHub Actions) | 3 |
| Code quality (linting, type hints) | 3 |

## 6. Community Engagement (10 points)

| Criteria | Points |
|----------|--------|
| Open source contributions | 4 |
| Stars received | 2 |
| Forks | 2 |
| Followers | 2 |

## 7. Portfolio Presentation (5 points)

| Criteria | Points |
|----------|--------|
| Demo links | 2 |
| Screenshots/GIFs in READMEs | 2 |
| Project descriptions | 1 |

---

## Score Interpretation

| Score | Rating |
|-------|--------|
| 90–100 | Elite |
| 80–89 | Strong |
| 70–79 | Good |
| 60–69 | Average |
| 50–59 | Below Average |
| Below 50 | Weak |

## Red Flags

- Empty repositories
- Only forked repos with no modifications
- No README files
- Exposed API keys or secrets
- Single massive commits
- Only tutorial/course assignment repos
- Inactive for 6+ months
