# Resume Rewrite Prompt

## Instructions

Rewrite resume bullet points to maximize impact, ATS compatibility, and recruiter engagement.

## Input Required

- Original resume bullets (or full resume)
- Target role
- Target company (optional)

## Rewrite Rules

Follow the formula from `knowledge/resume_best_practices.md`:

```
Action Verb + What You Did + Technology Used + Quantified Impact
```

## Process

1. **Identify Weak Bullets**
   - Missing action verbs
   - No metrics or quantification
   - Vague language ("responsible for", "worked on")
   - Missing technology mentions
   - Too long or too short

2. **Rewrite Each Bullet**
   - Start with a strong action verb
   - Include specific technologies
   - Add quantified results
   - Keep under 2 lines
   - Ensure ATS keyword inclusion

3. **Optimize Section Order**
   - Prioritize most impressive bullets first
   - Group related achievements
   - Ensure variety in action verbs

## Output Format

For each bullet:

```
ORIGINAL:
[original text]

REWRITTEN:
[improved text]

WHY BETTER:
- [reason 1]
- [reason 2]
```

Final output:

```
Bullets Rewritten: __/__
Improvement Areas:
- Added metrics to __ bullets
- Replaced __ weak verbs
- Added __ missing keywords
- Reduced __ bullets for conciseness

Overall Resume Impact: Before __/100 → After __/100
```
